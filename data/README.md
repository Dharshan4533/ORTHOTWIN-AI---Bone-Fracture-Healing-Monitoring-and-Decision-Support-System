# OrthoTwin AI — Data & Datasets Directory

This directory stores data validation reports, synthetic demonstration fixtures, and raw dataset extractions.

## Contents

- `DATASET_AUDIT_REPORT.md`: Empirical audit results generated by `training/dataset_validation.py`.
- `synthetic_demo/`: Clean, de-identified synthetic test images for automated testing.
- `raw/`: Extraction destination for training datasets (excluded from git).

## Ethical & Privacy Notice

OrthoTwin AI uses authorized public research datasets (Roboflow 100, FracAtlas) and synthetic fixtures.
No real Protected Health Information (PHI) is included in source control.
Any real clinical deployment requires IRB approval, HIPAA/GDPR-compliant data handling, and certified secure storage.
