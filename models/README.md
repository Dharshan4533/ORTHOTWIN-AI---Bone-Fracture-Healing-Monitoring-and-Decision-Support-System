# OrthoTwin AI — Model Storage & Checkpoints

This directory houses model configurations and trained weight checkpoints.

## Directory Structure

- `model_config.yaml`: Central specification of architectures, inference thresholds, and training hyperparameters.
- `weights/`: Checkpoint directory.
  - `fracture_yolov8.pt`: Trained YOLOv8 fracture detection weights.
  - `fracture_unet.pth`: Optional U-Net segmentation weights.
- `evaluation_report.json`: Metrics generated by `training/evaluate_detection.py`.

## Graceful Missing Weights Handling

If `weights/fracture_yolov8.pt` is absent, OrthoTwin AI runs in **unassisted clinical review mode** without throwing exceptions or crashing.
To configure a checkpoint:
1. Run `python training/train_detection.py` locally or in Google Colab.
2. Place the resulting `best.pt` file into `models/weights/fracture_yolov8.pt`.
3. Restart or reload the Streamlit application.
